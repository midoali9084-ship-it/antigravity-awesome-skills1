# Book PDF Splitter

## When to Use

- The user wants a book or long PDF divided into multiple smaller PDFs for easier study.
- Splitting should follow the book's existing principles, chapters, sections, or other clearly defined structural units.
- The original PDF content must stay exactly as-is: never edit, rewrite, summarize, compress, reformat, or alter any words or visual content.

## Objective

Split a book or long-form PDF into multiple smaller PDF files based on its existing internal structure, so that each resulting PDF contains approximately **2–3 principles, chapters, sections, or equivalent major units**.

The purpose is purely organizational:

> **Make the original book easier to study by dividing it into manageable PDF sections without changing the source in any way.**

---

## Core Rule

**Split. Do not edit.**

The source PDF must remain completely unchanged.

Do not:

- rewrite any text
- summarize anything
- remove anything
- add anything
- paraphrase anything
- correct anything
- translate anything
- reformat anything
- alter images
- alter typography
- alter page content
- regenerate pages
- recreate the document from extracted text

The resulting PDFs must contain the **original pages from the original PDF**.

---

## 1. Identify the Book's Existing Structure

First, inspect the PDF and identify its natural major divisions.

Depending on the book, these may be:

- Principles
- Chapters
- Parts
- Sections
- Rules
- Lessons
- Concepts
- Modules
- Other clearly defined major units

Use the structure that already exists in the book.

Do not invent a new organizational structure.

---

## 2. Group Major Units

Group the existing major units into study-friendly PDF sections.

Default target:

> **2–3 major units per PDF**

For example:

- PDF 1 → Principles 1–3
- PDF 2 → Principles 4–6
- PDF 3 → Principles 7–9
- PDF 4 → Principles 10–12

The exact grouping may vary depending on page length and the book's structure.

---

## 3. Prioritize Natural Boundaries

Never split a major unit in the middle merely to achieve an exact number of principles.

A principle, chapter, or section should remain intact whenever possible.

For example, if Principle 3 spans 25 pages:

> Keep all 25 pages together.

Do not split Principle 3 simply because doing so would create a more even page count.

The **existing structural boundary takes priority over equal file size**.

---

## 4. Page-Based Splitting

Once the boundaries of each major unit are identified, determine the corresponding page ranges in the original PDF.

Create each output PDF by copying the relevant original pages.

Do not reconstruct the PDF from extracted text or images.

The output should be a **page-level split of the original PDF**.

---

## 5. Preserve Every Page Exactly

Every source page must appear exactly once in the resulting collection unless the source contains pages that are intentionally excluded according to the user's instructions.

Preserve:

- text
- images
- graphics
- page numbers
- headers
- footers
- typography
- spacing
- formatting
- page dimensions
- hyperlinks where technically preserved by the PDF split
- bookmarks where technically preserved, if possible

Do not modify the contents of the pages.

---

## 6. No Content Loss

Before finalizing, verify that:

> **The complete original book is represented across the resulting PDFs.**

No page should accidentally be:

- omitted
- duplicated
- reordered
- truncated
- modified

The output PDFs should collectively contain the same pages as the original PDF, simply divided into smaller files.

---

## 7. Do Not Optimize for Equal File Size

The resulting PDFs do not need to have:

- equal page counts
- equal file sizes
- equal numbers of words

A 3-principle PDF may be much larger than a 2-principle PDF.

This is acceptable.

The primary objective is **logical study grouping**, not file-size balancing.

---

## 8. Naming

Name each output PDF clearly according to the original structure.

Preferred format:

`[Book Name] — Principles 1–3.pdf`

`[Book Name] — Principles 4–6.pdf`

If the book uses chapters:

`[Book Name] — Chapters 1–3.pdf`

If another structural unit is used:

`[Book Name] — [Unit X–Y].pdf`

Do not invent alternative titles or descriptions.

---

## 9. Edge Cases

If the book contains an introductory section before the first major principle/chapter:

Keep it with the first appropriate PDF unless doing so would create an unusually large section.

If the final PDF contains only one remaining major unit:

Keep it as its own PDF rather than artificially combining it with unrelated content.

If a book's structure makes 2–3 units per PDF impractical:

Prioritize:

1. preserving complete structural units
2. maintaining natural boundaries
3. keeping study sections reasonably sized
4. approximately 2–3 units per PDF

Do not violate structural boundaries simply to satisfy the 2–3 target.

---

## 10. Verification

After splitting, verify:

### Page Count
The total number of pages across all output PDFs matches the original PDF.

### Page Order
Pages remain in their original order.

### Boundary Accuracy
Each PDF begins and ends at an appropriate structural boundary.

### Content Integrity
No page content has been edited or regenerated.

### Completeness
Every original page appears in exactly one output PDF.

---

# Absolute Rules

1. **Never edit the source content.**
2. **Never rewrite the source content.**
3. **Never summarize the source.**
4. **Never remove content.**
5. **Never add content.**
6. **Never translate the source.**
7. **Never regenerate the pages from extracted text.**
8. **Use the original PDF pages directly.**
9. **Keep major structural units intact whenever possible.**
10. **Target approximately 2–3 major units per output PDF.**
11. **Prioritize natural structural boundaries over equal file sizes.**
12. **Ensure the complete original PDF is preserved across the resulting files.**

## Core Principle

> **The only transformation allowed is dividing the original PDF into smaller PDFs. Everything inside the pages must remain untouched.**
